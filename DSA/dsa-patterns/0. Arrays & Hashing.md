## Step-By-Step Approach

---

### Recognize It

- Problem gives you an array/string and asks about counts, duplicates, or pairs
- You keep saying "if only I could look this up in O(1)" → HashMap/HashSet
- Answer depends on a range sum computed repeatedly → Prefix Sum

---

### 1. Master These 5 Core Array/Hashing Patterns

| Pattern                  | Example Problem                       | Key Idea                                          |
| ------------------------- | -------------------------------------- | -------------------------------------------------- |
| 1. Frequency Map          | Two Sum, Group Anagrams                | HashMap of value/char → count or index             |
| 2. Prefix Sum             | Subarray Sum Equals K, Range Sum Query | Precompute cumulative sums for O(1) range queries  |
| 3. Kadane's Algorithm     | Maximum Subarray                       | Track running sum, reset when it goes negative     |
| 4. Sorting as Preprocess  | Merge Intervals, 3Sum                  | Sort first, then linear scan or two pointers       |
| 5. Index Mapping / Cyclic Sort | Find Missing Number, Find Duplicate | Use array index itself as a hash slot          |

---

### 2. Questions to Ask Yourself

1. Do I need O(1) lookup for "have I seen this before"?
2. Is the answer a running total or range sum? → Prefix sum
3. Would sorting simplify pair/triplet search?
4. Are values bounded by array length (1 to n)? → Cyclic sort / index-as-hash trick

### 4. Code Templates You Must Know

1. Prefix Sum + HashMap (Subarray Sum Equals K)

```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> freq{{0, 1}};
    int sum = 0, count = 0;
    for (int num : nums) {
        sum += num;
        count += freq[sum - k];
        freq[sum]++;
    }
    return count;
}
```

2. Kadane's Algorithm (Maximum Subarray)

```cpp
int maxSubArray(vector<int>& nums) {
    int best = nums[0], cur = nums[0];
    for (int i = 1; i < nums.size(); ++i) {
        cur = max(nums[i], cur + nums[i]);
        best = max(best, cur);
    }
    return best;
}
```

3. Cyclic Sort (First Missing Positive)

```cpp
int firstMissingPositive(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n; ++i) {
        while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            swap(nums[i], nums[nums[i] - 1]);
        }
    }
    for (int i = 0; i < n; ++i)
        if (nums[i] != i + 1) return i + 1;
    return n + 1;
}
```

4. Group Anagrams (Frequency Key)

```cpp
vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> groups;
    for (string& s : strs) {
        string key = s;
        sort(key.begin(), key.end());
        groups[key].push_back(s);
    }
    vector<vector<string>> res;
    for (auto& [k, v] : groups) res.push_back(v);
    return res;
}
```

### 5. Tips for Success

- HashMap first, sorting second — check if O(n) with a map beats O(n log n) with sorting
- Prefix sum turns "sum of range" questions from O(n) per query into O(1)
- For "duplicate/missing number in range 1..n" → cyclic sort beats extra space
- Watch for integer overflow on prefix sums with large arrays
- Draw the array with indices when a two-pointer or sliding approach isn't obvious
