# SDE Interview Prep Notes

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](LICENSE)

Software engineering (SDE) interview preparation notes: **DSA patterns with C++ templates**, **Low-Level Design (LLD)**, **System Design**, and **CS fundamentals** (OS, DBMS, Computer Networks, OOP). Built for coding interviews at product companies and FAANG.

## Contents

| Section | What's inside |
|---|---|
| [DSA Patterns](DSA/dsa-patterns/List%20of%20DSA%20Topics%20and%20Patterns.md) | Revision notes by topic and pattern: two pointers, sliding window, binary search, DP, graphs, trees, tries, and more, each with C++ templates |
| [DSA Code](DSA/codes/) | Solved C++ implementations: graphs, disjoint set, heaps, sparse table, recursion, sorting |
| [Questions Worth a Revise](DSA/questions-worth-a-revise/) | Curated problems flagged for repeat revision |
| [Problem Solving Framework](DSA/Problem%20Solving%20Framework.md) | How to approach a new problem |
| [Low-Level Design](LLD/README.md) | OOP, SOLID, design principles and patterns, interview tips, and 40+ LLD questions (parking lot, elevator, Splitwise, etc.) |
| [High-Level Design](HLD/) | System design interview framework |
| [CS Fundamentals](CS%20Fundamentals/) | OS, DBMS, Computer Networks, OOP |
