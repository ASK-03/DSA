## 4. Code Templates to Know

1. Core Bit Tricks Cheat Sheet (memorize this table)

| Operation                    | Code                        | Notes                                              |
| ----------------------------- | ---------------------------- | --------------------------------------------------- |
| Check if ith bit is set       | `x & (1 << i)`               | non-zero result means it's set                       |
| Get value of ith bit (0/1)    | `(x >> i) & 1`                | isolates it to exactly 0 or 1                        |
| Set ith bit                   | `x \| (1 << i)`               | turns bit i on, leaves others unchanged              |
| Clear ith bit                 | `x & ~(1 << i)`               | turns bit i off, leaves others unchanged             |
| Toggle ith bit                | `x ^ (1 << i)`                | flips bit i                                          |
| Get last k bits                | `x & ((1 << k) - 1)`         | same result as `x % (1 << k)` for `x >= 0`, but faster |
| Clear last k bits              | `x & ~((1 << k) - 1)`        | rounds `x` down to a multiple of `2^k`               |
| Check even/odd                | `x & 1`                       | `0` = even, `1` = odd                                |
| Multiply/divide by `2^k`      | `x << k` / `x >> k`           | bit shift beats `*`/`/` when k is known              |
| Remove lowest set bit          | `x & (x - 1)`                 | Brian Kernighan's — used to count set bits           |
| Isolate lowest set bit         | `x & (-x)`                    | two's complement trick, gives just that one bit      |
| Check power of two            | `x > 0 && (x & (x - 1)) == 0` | true only when exactly one bit is set                |
| Count set bits                | `__builtin_popcount(x)`       | or loop with Kernighan's if you can't use builtins   |
| Count trailing zeros          | `__builtin_ctz(x)`            | undefined behavior if `x == 0` — guard it            |
| Swap without a temp variable   | `a ^= b; b ^= a; a ^= b;`     | rarely needed, but interviewers still ask it         |
| Check if two numbers have opposite signs | `(a ^ b) < 0`      | sign bit differs → XOR is negative                   |

3. Count number of set bits (Brian Kernighan’s Algorithm)

```cpp
int countSetBits(int n) {
    int count = 0;
    while (n) {
        n &= (n - 1); // drops the lowest set bit
        count++;
    }
    return count;
}
```

4. Generate all subsets using bitmask

```cpp
vector<vector<int>> subsets(vector<int>& nums) {
    int n = nums.size();
    vector<vector<int>> res;
    for (int mask = 0; mask < (1 << n); ++mask) {
        vector<int> subset;
        for (int i = 0; i < n; ++i)
            if (mask & (1 << i)) subset.push_back(nums[i]);
        res.push_back(subset);
    }
    return res;
}
```

5. XOR Trick (Finding Unique Number)

```cpp
int singleNumber(vector<int>& nums) {
    int xorSum = 0;
    for (int x : nums) xorSum ^= x;
    return xorSum;
}
```

6. Power of Two

```cpp
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
```

7. Bitmask DP (TSP example)

```cpp
int tsp(int mask, int pos, vector<vector<int>>& dist, vector<vector<int>>& dp) {
    if (mask == (1 << dist.size()) - 1) return dist[pos][0]; // All visited
    if (dp[mask][pos] != -1) return dp[mask][pos];
    
    int ans = INT_MAX;
    for (int city = 0; city < dist.size(); ++city) {
        if ((mask & (1 << city)) == 0) {
            int newAns = dist[pos][city] + tsp(mask | (1 << city), city, dist, dp);
            ans = min(ans, newAns);
        }
    }
    return dp[mask][pos] = ans;
}
```

## 5. Tips for Success

- When generating all subsets or combinations, use mask from 0 to 2^n − 1
- Use `x & (x−1)` to remove the lowest set bit
- Use `x & −x` to isolate the lowest set bit
- Bitmasks are great for "states" — especially in DP or constraint selection
- XOR is your best friend for problems involving exactly 1 or 2 unique elements
