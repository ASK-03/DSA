## 1. Core Tree Patterns You Must Master

| Pattern                    | Example Problem               | Key Idea                                     |
| -------------------------- | ----------------------------- | -------------------------------------------- |
| 1. DFS Traversals          | Inorder, Preorder, Postorder  | Recursive or Stack-based traversal           |
| 2. Level Order Traversal   | BFS, Zigzag, Right View       | Use a queue with level tracking              |
| 3. Diameter of Tree        | Diameter of Binary Tree       | Track max depth + longest path via recursion |
| 4. Lowest Common Ancestor  | LCA of Binary Tree / BST      | Postorder logic or BST properties            |
| 5. Serialize / Deserialize | Convert Tree to String & back | Use preorder or level-order encoding         |
| 6. Binary Lifting          | LCA with many queries, Kth Ancestor | Precompute 2^k ancestors, jump in O(log n) |

---

## 2. Always Ask These for Tree Problems

1. Is it a Binary Tree or BST? 
2. Do I need to traverse all nodes or stop early?
3. What’s the traversal order required (pre, in, post)?
4. Am I reconstructing the tree, or finding properties?

## 4. Code Templates to Memorize

1. Inorder / Preorder / Postorder Traversal (Recursive)  

```cpp
void inorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    inorder(root->left, res);
    res.push_back(root->val);
    inorder(root->right, res);
}
```

2. Level Order Traversal (BFS)

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;
    if (!root) return res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int size = q.size();
        vector<int> level;
        for (int i = 0; i < size; ++i) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
```

3. Diameter of Binary Tree

```cpp
int diameter = 0;
int dfs(TreeNode* node) {
    if (!node) return 0;
    int left = dfs(node->left);
    int right = dfs(node->right);
    diameter = max(diameter, left + right);
    return 1 + max(left, right);
}
int diameterOfBinaryTree(TreeNode* root) {
    dfs(root);
    return diameter;
}
```

4. Lowest Common Ancestor (Generic Tree)

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
    TreeNode* left = lowestCommonAncestor(root->left, p, q);
    TreeNode* right = lowestCommonAncestor(root->right, p, q);
    if (left && right) return root;
    return left ? left : right;
}
```

5. Serialize and Deserialize (Preorder with Nulls)

```cpp
// Serialize
void serialize(TreeNode* root, string& res) {
    if (!root) { res += "# "; return; }
    res += to_string(root->val) + " ";
    serialize(root->left, res);
    serialize(root->right, res);
}

// Deserialize
TreeNode* deserialize(istringstream& ss) {
    string val;
    ss >> val;
    if (val == "#") return nullptr;
    TreeNode* node = new TreeNode(stoi(val));
    node->left = deserialize(ss);
    node->right = deserialize(ss);
    return node;
}
```

6. Binary Lifting (LCA with Multiple Queries)

The postorder LCA above is O(n) per query — fine for one-off queries. When you get many LCA queries on a fixed tree, precompute in O(n log n) and answer each query in O(log n).

`up[k][v]` = the 2^k-th ancestor of node `v`. Build it once, then jump `p`/`q` up in powers of two.

```cpp
const int LOG = 20; // enough for n up to ~10^6
vector<vector<int>> up;
vector<int> depth;

void dfs(int node, int parent, vector<vector<int>>& adj) {
    up[0][node] = parent;
    for (int k = 1; k < LOG; k++)
        up[k][node] = (up[k-1][node] == -1) ? -1 : up[k-1][up[k-1][node]];
    for (int nei : adj[node]) {
        if (nei != parent) {
            depth[nei] = depth[node] + 1;
            dfs(nei, node, adj);
        }
    }
}

void buildLCA(int n, int root, vector<vector<int>>& adj) {
    up.assign(LOG, vector<int>(n, -1));
    depth.assign(n, 0);
    dfs(root, -1, adj);
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    int diff = depth[u] - depth[v];
    for (int k = 0; k < LOG; k++)
        if (diff & (1 << k)) u = up[k][u];

    if (u == v) return u;

    for (int k = LOG - 1; k >= 0; k--) {
        if (up[k][u] != up[k][v]) {
            u = up[k][u];
            v = up[k][v];
        }
    }
    return up[0][u]; // one step above where they diverge
}
```

- Step 1: lift the deeper node up to match the other's depth.
- Step 2: lift both together from the highest power of two down, stopping just before they'd meet — the answer is one more step up.
- Also the base technique for Kth ancestor queries: reuse `up[][]` alone, skip the `lca` half.

## 5. Tips for Tree Mastery

- Master the recursive template first, then convert to iterative if needed
- Draw the tree on paper — visualize traversal orders
- In LCA, use postorder because decisions depend on left/right subtree returns
- Use queues for level traversal, recursion for depth-first insights
- Use null markers when serializing trees
